# Equity Analysis

## Project Overview
Help investors and positional traders to make right decisions for investment and trading by doing the fundamental and technical analysis.

## Pre-requisite
* Make sure the `ANTHROPIC_API_KEY=<<your key>>` is part of system path.

## How to install
use command `pip install -r requirements.txt`

## Architecture summary
* `src/` - a source folder (good to have proper package structure)
* `tests/` - folder to holds the tests.(good to have proper package structure as per the source folder)
* `notebooks/` - experimentation, exploration, analysis, and learning rather than for the final production code
* `data/` - runtime cache, added to `./.gitignore`
* `reports/` - any generated reports as part of the analysis, added to `./.gitignore`

## Languages
* python as a programming language

## libraries
* yfinance - to get the financial information, uses API calls
* anthropic - to be added, when required
